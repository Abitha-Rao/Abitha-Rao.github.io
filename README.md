# The Abitha Show

The source code for my product portfolio website, live at **https://abitha-rao.github.io/**.

The site presents my career as a TV series. Each stage (NIT Warangal, Qualcomm, ISB) is a "season", and each project or result is an "episode" with a one-line story and a headline number. It is written for recruiters and product teams hiring for APM and product roles from 2027.

## What is on the page

It is a single page with these sections, top to bottom:

- **Hero**: the show title, a short tagline and two buttons.
- **Previously on**: a three-card recap of the story so far.
- **Seasons**: one tab per season; picking a tab shows that season's episodes.
- **Spin-offs**: side projects, each with a link to its code and, where one exists, a live demo.
- **Awards**: headline numbers.
- **Behind the scenes**: a scrapbook of personal notes and the tools I use.
- **End credits**: how to contact me (LinkedIn and GitHub).

## What you need

- [Node.js](https://nodejs.org) with npm. I checked the commands below with Node 26; the repo does not pin a version.
- No accounts, keys or environment settings.

## Run it on your computer

```bash
git clone https://github.com/Abitha-Rao/Abitha-Rao.github.io.git
```

```bash
cd Abitha-Rao.github.io
```

```bash
npm install
```

```bash
npm run dev
```

Then open http://localhost:3000. The page reloads when you save a file.

## Change the content

All the words and numbers live in one file, [lib/show.ts](lib/show.ts): the profile, the recap cards, the seasons and episodes, the spin-offs, the awards, the scrapbook and the tools list. Edit that file to change what the site says.

| File | What it holds |
| --- | --- |
| [lib/show.ts](lib/show.ts) | All the content |
| [app/page.tsx](app/page.tsx) | The page layout, section by section |
| [app/components/Seasons.tsx](app/components/Seasons.tsx) | The season tabs and episode cards |
| [app/globals.css](app/globals.css) | Colours, fonts and animations |

## Build and publish

```bash
npm run build
```

This writes a plain, static copy of the site (HTML, CSS and JavaScript files that need no server) to a folder called `out/`. The site is built with [Next.js](https://nextjs.org) 16 and Tailwind CSS 4, set to static export in [next.config.ts](next.config.ts).

GitHub Pages serves the live site from this repo's `gh-pages` branch, so publishing means putting the contents of `out/` on that branch. There is no script or automation for that step in this repo; it is done by hand.

## Status and limits

- A personal site. The content is about me and is not meant to be reused as it is, though you are welcome to borrow the structure.
- One page only. There is no blog, contact form or analytics.
- There are no automated tests.
- The `AGENTS.md` file is a note for AI coding tools, generated by Next.js. It is not documentation for people.
